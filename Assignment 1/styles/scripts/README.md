# Shapes and Forms Application

## Description
This application allows users to calculate the area of various geometric shapes including rectangles, circles, and triangles.

## Form Data Passing
Form data is passed to `result.html` via the query string using the GET method.

## Area Calculation Formulas
- Rectangle: Area = width * height
- Circle: Area = π * radius²
- Triangle: Area = 0.5 * base * height
